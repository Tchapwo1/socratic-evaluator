Deterministic philosophical argumentation, moral dilemma evaluation, and Socratic reasoning skill for AI agents, benchmark suites, and educational tools.

---

## ⚡ What this contains

- **85 Multi-Level Philosophical Inquiries:** 10 levels of epistemological, ethical, and metaphysical dilemmas (Plato, Descartes, Kant, Sartre, Nietzsche, Rousseau, Hannah Arendt).
- **Philosophical Distinction Matrices:** Absolu/Relatif, En fait/En droit, En théorie/En pratique, Idéal/Réel, Médias/Fins.
- **Tripartite Dialectical Engine:** Automated generation of Hegelian dissertation architectures (Thèse / Antithèse / Synthèse).

---

## 🚀 Quick Start

### 1. Query by Concept or Author
```bash
python scripts/evaluate.py query "Kant" --format text
```

### 2. Generate Dialectical Outline
```bash
python scripts/evaluate.py outline "La liberté consiste-t-elle à faire ce que l'on veut ?"
```

### 3. List Standard Inquiry Prompts
```bash
python scripts/evaluate.py prompts
```
